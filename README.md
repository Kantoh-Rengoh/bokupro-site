# ESY 選手成長予測（ぼくのプロ野球 ダッシュボード）

「ぼくのプロ野球」の選手成長予測ダッシュボードを、単体で動く Web サイトにしたものです。
GitHub Pages に置くだけで公開できます。

## ファイル構成

```
bokupro-site/
├ index.html          … ページ本体（見出し・ボタンなどの骨組み）
├ css/style.css       … 見た目（ライト／ダークモード、スマホ対応）
├ js/app.js           … data/ の JSON を読み込んで表示する処理
├ data/players.json   … 選手データ（毎年これを差し替える）
├ data/qa.json        … 質問と回答（質問が増えたら追記）
├ .nojekyll           … GitHub Pages 用の空ファイル（消さないでください）
├ README.md           … このファイル
└ original-dashboard.html … 元ページ（参考用。公開には不要）
```

## 毎年の更新のしかた

1. 新しいセーブデータから `players.json` を作る（今までと同じ形式）
2. `data/players.json` を新しいファイルで上書きする
3. GitHub にアップロードする（下の「更新をアップロードする」参照）

それだけで、人数・注目新人・一覧・年号の文言がすべて新しいデータに切り替わります。

### 年号について

「セーブ時点（2157年2月・ウィンターリーグ後）」「2156年開幕時からの伸び」の年号は、
`players.json` の中で一番新しいドラフト年＋1 をシーズン年として自動計算しています
（例：2156年ドラフトの新人がいれば 2157年）。

「2月・ウィンターリーグ後」などの文言を変えたいときは `js/app.js` の先頭にある
`NOTE_SAVE` と `NOTE_BASE` の2行を書き換えてください。`{Y}` がシーズン年、`{Y1}` がその前年に置き換わります。

### 質問を増やしたいとき

`data/qa.json` に同じ形式で1件追加します。`本文` の書き方は次の3種類です。

- `|列1|列2|列3` … 「|」で始まる行は表になります（最初の行が見出し）
- `- 文章` … 「- 」で始まる行は箇条書きになります
- それ以外の行 … ふつうの段落になります

## パソコンで直接開くと「データの読み込みに失敗」と出る理由

`index.html` をダブルクリックで開くと、ブラウザの安全機能で `data/` の JSON を読み込めません。
これは故障ではありません。GitHub Pages で公開した URL から開けば正常に表示されます。

## GitHub Pages で公開する手順（初めての人向け）

パソコンに特別なソフトは要りません。ブラウザだけで完了します。

### 1. GitHub のアカウントを作る

1. https://github.com/ を開き、右上の「Sign up」を押す
2. メールアドレス・パスワード・ユーザー名を決めて登録する
   - **ユーザー名が公開 URL の一部になります**（例：`https://ユーザー名.github.io/bokupro-site/`）
3. 届いたメールで認証を済ませる

### 2. リポジトリ（置き場所）を作る

1. ログイン後、右上の「+」→「New repository」を押す
2. 「Repository name」に `bokupro-site` と入力する（別の名前でも可。URL の一部になります）
3. 「Public」を選ぶ（無料で公開するには Public が必要です）
4. ほかはそのままで、緑の「Create repository」を押す

### 3. ファイルをアップロードする

1. 作成直後の画面にある「uploading an existing file」というリンクを押す
2. エクスプローラーで `bokupro-site` フォルダを開き、次のものを選んでブラウザの点線枠にドラッグ＆ドロップする
   - `index.html`
   - `css` フォルダ（フォルダごと）
   - `js` フォルダ（フォルダごと）
   - `data` フォルダ（フォルダごと）
   - `.nojekyll`
   - `README.md`
   - ※ `original-dashboard.html` は不要です
3. 一覧にファイルが並んだら、下の緑の「Commit changes」を押す

### 4. 公開をオンにする

1. リポジトリの上のタブ「Settings」を押す
2. 左のメニューから「Pages」を押す
3. 「Build and deployment」の「Source」が「Deploy from a branch」になっていることを確認する
4. 「Branch」で `main` を選び、右の欄は `/ (root)` のまま「Save」を押す
5. 1〜2分待ってページを再読み込みすると、上部に「Your site is live at https://…」と URL が出ます

この URL がダッシュボードのアドレスです。スマホからも開けます。

### 更新をアップロードする（毎年の作業）

1. GitHub でリポジトリを開き、`data` フォルダをクリックする
2. 右上の「Add file」→「Upload files」を押す
3. 新しい `players.json` をドラッグ＆ドロップする（同じ名前なので上書きされます）
4. 「Commit changes」を押す
5. 1〜2分ほどで公開ページに反映されます（反映されないときはブラウザで再読み込み）

## 見た目の変更

色はすべて `css/style.css` の先頭にある変数で決めています。
`:root { … }` がライトモード、`[data-theme="dark"]` がダークモードです。
